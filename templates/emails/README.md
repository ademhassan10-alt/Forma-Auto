# Email templates

The wording and layout of each automatic email lives here, one file per email
(welcome, intro offer follow-up, win-back, pack expiry, regulars offer).
Keeping text separate from code means Eren's wording can be changed without touching the logic.
Placeholders like `{first_name}` are filled in per client when the email is sent.
Every marketing email must include the unsubscribe link.
